# WAYA Mobile

Prototype Expo / React Native de WAYA.

## Lancer le projet

```bash
npm install
npm start
```

Ensuite, scanne le QR code avec Expo Go.

## Fonctionnalites de cette base

- Carte mobile centree sur Montceau-les-Mines ou sur la position GPS.
- Missions reelles avec coordonnees.
- Fiche mission avec GPS, preuve photo et validation dans un rayon donne.
- Progression locale sauvegardee sur le telephone.
- Navigation Personnes / Missions / Profil.
